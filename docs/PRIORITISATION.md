# Prioritisation — NOW / RESEARCH / LATER

| Capability | Decision | Justification |
|---|---|---|
| Measurement ontology, PMO spec, job-family schema | **NOW** | Everything else depends on clear constructs and editable definitions. |
| Context-adjusted delivery analysis with uncertainty | **NOW** (exists) | Core differentiator; already validated on synthetic data. |
| Plain-English explanations, "How was this assessed?" | **NOW** | Business users must not need statistics to use the product. |
| Evidence chains with manual attribution | **NOW** | Prevents automatic attribution of team outcomes to one person. |
| 30-day milestone risk classifier | **NOW** | Clear, valid, project-level target with operational value; no person scoring. |
| Research Laboratory (EDA, tests, model comparison, run history) | **NOW** (for researchers) | Makes the science inspectable and reproducible. |
| Scenario lab A–F | **NOW** | Demonstrates the product's thesis in controlled conditions. |
| Clustering & PCA of project environments | **RESEARCH** | Exploratory; useful for bottleneck discovery, not for decisions. |
| Random-slope growth models | **RESEARCH** | Under-powered per person; population-level insight only for now. |
| Causal DAG analyses, E-values | **RESEARCH** | Disciplines claims; no causal claims surface to business users. |
| Coordinator A/B experiment framework | **RESEARCH** | Needs consented pilots for real evidence; simulation shows the design. |
| Composite indicators | **LATER** | Not justified; would require validity evidence first. |
| Survival models for overdue milestones | **LATER** (v0.3) | Replaces the right-censoring guard. |
| Production connectors, SSO, multi-tenant hardening | **LATER** (Phase E) | Requires authorised integrations and security review. |
| Additional job families beyond the illustrative example | **LATER** | Each needs its own job analysis and validation. |
| LLM-generated explanations | **LATER** | Template narratives from computed values are verifiable; generated language would need labelling and review. |
